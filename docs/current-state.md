# Implementation scope

[Project home](../README.md) · [Build and content workflow](website-workflow.md)

The published site provides 14 curated component profiles across web applications, services, command-line tools, automation and native mobile. Human pages and agent guidance include selection, chosen-stack building and explicit migration workflows, complete Markdown/JSON records and source references.

The optional context router validates explicit requirements and returns resources, candidates, exclusions and questions. It calls no model and stores no application data. Known-stack work preserves the choice; new-stack comparisons and migration planning keep constraints and unknowns explicit. The visiting agent interprets the application conversation and reasons about the result.

Initial HTML, matching page Markdown, JSON exports, canonical sitemap, crawler policy and factual contact resources support ordinary browsing and direct retrieval. Production uses Cloudflare Pages with Functions; local responses have noindex headers and exclude analytics. Aggregate pageviews load only on the canonical production origin. The preview uses the same routing and format handlers.

Core official guidance and all 394 cited source addresses were checked on 13 October 2026. Original research dates and check scope remain separate in the [freshness snapshot](../menu/inputs/research/freshness.json). Recipes, full dependency combinations, application capacity and migrations require qualification in the actual project; this reference does not certify compatibility or measured cross-stack rankings.

Build and local rendered/direct checks cover desktop and phone views, contact representations, routing, malformed input, true missing pages and resource parity. These are website checks, not execution evidence for every application recipe. The real demonstration is included in the released site; the dated status below records its release and verification boundary.
