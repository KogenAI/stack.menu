## Local changes — 23 October 2026

### Record the published 23 October source base

The reviewed base `9aa317f` was pushed on 23 October. Its recorded deployment was queued at readback; this is source-publication evidence, not a later live-delivery check.

### Store Expo alternatives as complete list items

Expo alternatives are arrays of complete strings in the curated record. The generated lint/TypeScript starter failures remain a separate, unresolved qualification limit.

### Clarify unsupported source component requests

A requested component absent from the source now produces an explicit clarification instead of treating target coverage as sufficient source evidence.

### Preserve Expo when routing mobile requirements

Mobile component labels no longer inject SwiftUI or Compose resources into a chosen Expo build. Client architecture and a shared backend remain separate questions.

### Keep chooser selection from scrolling the page

Selecting a chooser task updates its result in place instead of triggering reveal scrolling.

### Let long chooser labels wrap inside controls

Chooser option and clear-selection controls grow with wrapped text, preserving readable labels and focus indicators on narrow screens.

### Make inline text links visibly interactive

Inline text links have underlines and visible hover/focus states in the shared interactive styles.

### Separate form labels in negotiated Markdown

Generated page Markdown separates form labels and select options instead of concatenating their text.

### Qualify async costs in Rust CLI advice

The Rust CLI alternative makes asynchronous-runtime complexity conditional on the workload; ordinary synchronous CLIs do not require an async runtime.
