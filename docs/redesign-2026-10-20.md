## Functional adaptations

- All 14 folders link to working guides, recommendations and rewrite planning. Library search/type filtering, zero-result recovery and comparison of up to three stacks work.
- Comparison rows use current profile facts; all complete-guide actions have real destinations. Invalid or inherited-object URL values are ignored.
- Recommendation choices filter by application type and produce shareable URLs. They do not call a model or infer unstated requirements.
- Rewrite selectors work across all profiles, validate identical stacks and produce current contract/phase guidance plus copyable/downloadable briefs.
- Guide sections remain in initial HTML, including all 18 October generator content and migration material. Tool choices add their purpose, limits and sources to the agent brief. Copy/download and plain Markdown/JSON links work.
- Header/footer render on the server. Mobile navigation handles Escape, keyboard focus and background interaction. Essential links remain available without JavaScript.
- The video area links to agent instructions while recording is pending. The designer’s scripted conversation visibly says it is illustrative. Agent names use text because the prototype’s logo-source notice was missing.
- Tailwind compiles at build time. Executable scripts remain external; the shared security policy allows the designer’s inline style attributes and image data only where needed for visual components.
