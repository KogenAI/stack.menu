Bruno

An API client that keeps your requests in Git.

Bruno lets you send API requests and save them in collections. Collections are stored as text files, so you can keep them in the same repository as your code and review changes in a pull request.

Where it fits

If you’re building an app that exposes or consumes an API, you can use Bruno for API testing and to share the requests you use during development. You can also run collections from the command line.
